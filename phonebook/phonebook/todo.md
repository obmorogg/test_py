Теперь добавьте использование стандартной библиотеки.

## 1. Проверка номера телефона

Используйте `re`.

Допустимы номера:

```text
+79991234567
89991234567
```

Номер должен:

* начинаться с `+7` или `8`;
* после этого содержать 10 цифр.

Создайте исключение:

```python
InvalidPhoneError
```

которое наследуется от:

```python
PhoneBookError
```

Некорректный номер сохранять нельзя.

---

## 2. Дата создания контакта

При создании `Contact` сохраняйте дату и время:

```python
created_at
```

Используйте:

```python
datetime.now()
```

При выводе контакта отображайте дату в формате:

```text
дд.мм.гггг чч:мм
```

Например:

```text
Анна | +79991234567 | 11.09.2026 14:30
```

---

## 3. Случайный контакт

Добавьте в `PhoneBook` метод:

```python
random_contact()
```

Метод должен возвращать случайный контакт с помощью `random.choice()`.

Если справочник пуст, вызывайте:

```python
ContactNotFoundError
```

# Проект: Телефонный справочник. Часть 7

Продолжите работу с телефонным справочником.

Теперь контакты должны сохраняться между запусками программы.

Используйте:

* `pathlib`;
* JSON;
* `with`.

В этой версии сохраняются объекты:

```python
PersonalContact
WorkContact
```

## Структура данных

Добавьте папку:

```text
data/
```

Контакты храните в:

```text
data/contacts.json
```

Если папки `data` нет, программа должна создать её автоматически при создании объекта `PhoneBook`.

---

## 1. Сохранение контактов

Добавьте в `PhoneBook` метод:

```python
save()
```

Он должен сохранять контакты в JSON.

Для каждого контакта сохраняйте:

* тип контакта;
* имя;
* телефон;
* дату создания;
* `relation` для личного контакта;
* `company` для рабочего контакта.

### Пример JSON

```json
[
    {
        "type": "personal",
        "name": "Анна",
        "phone": "+79991234567",
        "created_at": "2026-09-15 18:30:00",
        "relation": "друг"
    },
    {
        "type": "work",
        "name": "Иван",
        "phone": "89991234567",
        "created_at": "2026-09-15 18:35:00",
        "company": "SkyPro"
    }
]
```

---

## 2. Загрузка контактов

Добавьте метод:

```python
load()
```

Он должен загружать данные из:

```text
data/contacts.json
```

Если файла ещё нет, справочник остаётся пустым.

Если JSON повреждён, обработайте:

```python
json.JSONDecodeError
```

и выведите:

```text
Не удалось загрузить контакты
```

---

## 3. Автоматическое сохранение

После:

* добавления;
* изменения;
* удаления

контакта автоматически вызывайте:

```python
save()
```

При запуске программы один раз вызывайте:

```python
load()
```

Если проект работает через Poetry, NumPy должен быть добавлен как основная зависимость проекта.

## Метод statistics()

Добавьте в `PhoneBook` метод:

```python
statistics()
```

Исходные данные справочника хранятся в виде объектов Python, поэтому **разрешается один раз преобразовать данные контактов в NumPy-массивы**.

После этого все статистические вычисления должны выполняться средствами NumPy.

Создайте массив длин имён контактов.

На его основе определите:

* количество контактов;
* минимальную длину имени;
* максимальную длину имени;
* общее количество символов;
* среднюю длину имени.

Также создайте NumPy-массивы для определения количества:

* личных контактов;
* рабочих контактов.

После формирования массивов не используйте обычные Python-функции:

```python
sum()
min()
max()
```

для статистических вычислений.

### Пример

В справочнике находятся:

```text
Анна
Александр
Мария
Константин
```

Анна и Мария — личные контакты.

Александр и Константин — рабочие.

### Результат

```text
Всего контактов: 4
Личных: 2
Рабочих: 2

Минимальная длина имени: 4
Максимальная длина имени: 10
Всего символов: 28
Средняя длина имени: 7.0
```

